# DemoBase — Navigation au clavier

DemoBase est entièrement utilisable au clavier. Cette page liste tous les raccourcis disponibles.

---

## Navigation dans l'application

### Sidebar (toujours actifs)

| Raccourci | Destination |
|---|---|
| `Alt+1` | Releases |
| `Alt+2` | Groups |
| `Alt+3` | Artists |
| `Alt+4` | Platforms |
| `Alt+5` | Parties |
| `Alt+6` | Favoris Releases |
| `Alt+7` | Favoris Soundtracks |
| `Alt+8` | Favoris Graphics |
| `Alt+E` | Émulateurs |
| `Alt+P` | Préférences |

### Historique

| Raccourci | Action |
|---|---|
| `Alt+←` | Retour (page précédente) |
| `Backspace` | Retour (hors d'un champ de saisie) |
| `Échap` | Retour (hors d'un champ de saisie) |

---

## Liste des releases

| Raccourci | Action |
|---|---|
| `↑` / `↓` | Naviguer entre les releases |
| `Entrée` | Ouvrir la fiche de la release sélectionnée |
| `F5` | Lancer directement la release sélectionnée |
| `Ctrl+F` | Mettre le focus sur la recherche |
| `/` | Mettre le focus sur la recherche (hors champ de saisie) |
| `Page↑` / `Page↓` | Défiler d'une page |
| `Début` / `Fin` | Aller en haut / bas de la liste |

---

## Fiche détail d'une release

| Raccourci | Action |
|---|---|
| `F5` | Lancer la release |
| `F` | Toggle favori (hors champ de saisie) |
| `Échap` | Retour à la liste |
| `1` | Onglet Info |
| `2` | Onglet Crédits |
| `3` | Onglet Used In |
| `4` | Onglet Média |
| `5` | Onglet Files |

---

## Lecture audio (Soundtracks)

Les raccourcis de lecture sont gérés par le lecteur audio intégré (TrackerPlayer). Se référer aux contrôles affichés dans l'interface (Lecture/Pause/Stop/Suivant/Précédent).

---

## Notes

- Les raccourcis `Backspace`, `Échap`, `/` et `F` n'agissent **pas** lorsque le focus est dans un champ de saisie (TextBox) — ils fonctionnent normalement pour la saisie de texte.
- `F5` fonctionne aussi bien depuis la liste (sur la release sélectionnée) que depuis la fiche détail.
- La navigation historique (`Alt+←`, `Backspace`, `Échap`) mémorise tous les changements de vue et permet de revenir pas à pas.
